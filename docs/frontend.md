# Frontend Documentation

## Overview
The Klyptic Frontend is a modern, responsive, and highly interactive web application built to serve as the user interface for the AI Engine and Knowledge Base. It is designed with performance, accessibility, and modern aesthetics in mind.

## Technology Stack
- **Framework:** React 19 with TanStack Start
- **Bundler:** Vite
- **Routing:** TanStack Router (`@tanstack/react-router`)
- **State Management & Data Fetching:** TanStack Query (`@tanstack/react-query`)
- **Styling:** TailwindCSS v4 with `tw-animate-css` for animations
- **UI Components:** Radix UI primitives (headless, accessible components) styled with TailwindCSS (similar to shadcn/ui).
- **Forms & Validation:** React Hook Form (`react-hook-form`) combined with Zod (`zod`) for schema validation.
- **Icons:** Lucide React (`lucide-react`)
- **Date Handling:** `date-fns` and `react-day-picker`
- **Charts:** Recharts (`recharts`)
- **Language:** TypeScript

## Architecture & Structure
The frontend is built using a component-driven architecture. 
- **Routing:** Uses file-based routing via TanStack Router. This ensures type-safe routing and optimal code splitting.
- **Data Fetching:** TanStack Query manages server state, caching, and background synchronization, ensuring the UI remains snappy while interacting with the Express backend.
- **UI Kit:** Relies heavily on Radix UI for accessible primitives (Accordions, Dialogs, Dropdowns, Popovers, Tabs, etc.). These primitives are unstyled by default and are styled using Tailwind CSS classes to maintain a consistent design system.
- **Form Handling:** Forms are strictly typed using Zod schemas and managed by React Hook Form to prevent unnecessary re-renders.

## Key Features & Responsibilities
1. **Knowledge Capture UI:** Provides interfaces (like modals and forms) to upload PDFs, images, paste YouTube URLs, or write text notes. It handles the initial validation before sending payloads to the backend.
2. **Immediate Feedback:** When capturing knowledge, it optimistically updates the UI or relies on the backend's fast `200 OK` response while the AI Engine processes the data in the background (preventing the user from staring at a loading spinner for large files).
3. **Search & RAG Chat Interface:** A dedicated chat UI that communicates with the backend's search and chat endpoints, allowing users to query their knowledge base in natural language.
4. **Insights Dashboard:** Uses Recharts to visualize user knowledge trends and summaries generated by the AI engine.

## Developer Workflow
- **Development Server:** `npm run dev` (starts Vite dev server)
- **Build:** `npm run build` (creates production bundle via Vite)
- **Linting & Formatting:** Managed via ESLint and Prettier (`npm run lint`, `npm run format`).

## Environment Variables
The frontend expects environment variables (typically prefixed with `VITE_`) to know where the Express backend is hosted. It does *not* talk to the Python AI engine directly; all requests route through the Node.js backend.
